INFORMACIÓN Y CONFIANZA

Política de privacidad

Tu configuración vive en tu equipo. Aquí explicamos qué ocurre al visitar este sitio, utilizar la aplicación y conectar tus herramientas de creación.

Última actualización: 23 de octubre de 2026.

El sitio y la aplicación son independientes.

Este sitio presenta JATSI Control y su documentación. No se conecta a la aplicación de tu equipo, no inicia sesiones con plataformas ni recibe tus credenciales.

1. Alcance y contacto

Esta política describe las prácticas del proyecto JATSI Control en este sitio y el funcionamiento de su aplicación de escritorio. Las consultas y solicitudes relativas a información compartida con el proyecto pueden dirigirse al canal de soporte en GitHub.

Los reportes de GitHub son públicos. Comparte únicamente la información indispensable, por ejemplo el enlace de un reporte que quieras corregir o retirar. No publiques contraseñas, tokens, claves, archivos de configuración completos ni datos personales de tu audiencia.

2. Información de este sitio web

El sitio está compuesto por páginas estáticas, imágenes y demostraciones visuales. No incorporamos herramientas de analítica, cookies de seguimiento ni formularios para recopilar datos. Las interacciones de demostración se ejecutan en el navegador y utilizan datos ilustrativos.

El alojamiento en GitHub Pages procesa información técnica de acceso. GitHub indica que registra la dirección IP de quienes visitan páginas alojadas en este servicio para fines de seguridad. Puedes consultar la declaración de privacidad de GitHub. Los enlaces externos te llevan a servicios que aplican sus propias políticas.

3. Información de la aplicación de escritorio

Según las funciones que utilices, JATSI Control puede guardar localmente perfiles y canales, preferencias, reglas de automatización, configuraciones de overlays, recursos que importes y registros de actividad o estadísticas de tus sesiones. Los eventos de un directo pueden incluir nombres de usuario, avatares, mensajes y otras interacciones que entregue la plataforma conectada.

La aplicación necesita estos datos para mostrar la actividad, ejecutar las acciones configuradas y mantener la continuidad de tu espacio de trabajo. La información puede conservarse en archivos y bases de datos del equipo. Este sitio web no ofrece acceso remoto a esos archivos.

4. Integraciones y credenciales

Cuando configuras una integración, la aplicación se comunica con el proveedor o la herramienta correspondiente y envía los datos necesarios para realizar la función solicitada. Esto puede incluir el canal seleccionado, una solicitud de autorización, identificadores, eventos o acciones. Cada servicio determina sus propios permisos, disponibilidad y tratamiento de datos.

Para las autorizaciones implementadas, las credenciales se guardan mediante el almacén del sistema operativo cuando está disponible. En entornos donde ese almacén no está disponible, existe un mecanismo alternativo de archivos locales. El nivel de protección también depende de la seguridad del equipo y de su configuración.

Las versiones de JATSI Control con conexión oficial de TikTok utilizan Login Kit y Display API para consultar los datos que decidas autorizar: nombre y avatar, identificadores de cuenta, usuario, biografía, enlace de perfil y verificación; seguidores, seguidos, me gusta acumulados y cantidad de videos públicos; y videos públicos con sus títulos, fechas, imágenes y contadores de vistas, me gusta, comentarios y compartidos. Estos datos permiten identificar la cuenta conectada, consultar su crecimiento y comparar el rendimiento de sus publicaciones.

La consulta se realiza desde la aplicación al servicio de TikTok. Las credenciales y los datos consultados permanecen en el equipo o servidor local donde ejecutes JATSI; el sitio público no recibe esos datos. Las imágenes y enlaces de perfil o videos pueden cargar contenido desde TikTok. Puedes exportar las mediciones a un archivo que tú guardas y controlas. La conexión de lectura no publica contenido en tu nombre.

La conexión al chat y los eventos de TikTok LIVE funciona por separado. De forma opcional, puedes vincular una sesión de TikTok LIVE para consultar los emotes de Club de Fans y Súper Fan. Esa sesión permite un acceso más amplio a la cuenta que la autorización oficial de lectura: el inicio de sesión se realiza en una ventana temporal de navegador y la aplicación conserva localmente los datos de sesión necesarios para consultar el catálogo. Puedes quitar ese acceso desde la sección de emotes; el último catálogo puede permanecer en el equipo para usarlo en sonidos y alertas.

5. Conservación, acceso y eliminación

El historial de estadísticas oficiales de TikTok comienza con las consultas realizadas en JATSI y conserva mediciones por hora de hasta un año. Se guarda por perfil y cuenta autorizada. La actualización de estadísticas y videos se realiza cada 15 minutos mientras el panel está abierto; no se recupera un historial anterior a esas consultas. Al desconectar la cuenta oficial desde JATSI, se revoca su autorización en TikTok y se eliminan las mediciones y la lista de videos guardadas por esta función para ese perfil. Si no se puede contactar con TikTok para completar la desconexión, la aplicación conserva la conexión para que puedas reintentarlo.

Los datos locales permanecen en tu equipo mientras se conserven los perfiles, archivos o bases de datos correspondientes. Puedes gestionar los perfiles y las conexiones desde la aplicación y solicitar orientación para localizar o eliminar los datos locales. Desinstalar la aplicación puede dejar archivos de configuración o historial.

Desconectar una integración, borrar un perfil y retirar permisos desde un proveedor pueden producir resultados diferentes. Revisa también las opciones de aplicaciones autorizadas de cada servicio para gestionar los permisos concedidos.

Para solicitar acceso, corrección o eliminación de información que hayas comunicado en un reporte del proyecto, abre una solicitud de soporte indicando el enlace del contenido. Si la gestión requiere información sensible, solicita primero un canal adecuado; no la incluyas en el reporte público. Los datos de tu equipo y los almacenados por terceros deben gestionarse en su ubicación correspondiente.

6. Cuidado de tu información

Protege el acceso a tu equipo, utiliza únicamente los permisos necesarios y revisa los recursos que compartes durante un directo. Antes de adjuntar capturas o registros a un reporte, oculta datos de audiencia, claves de conexión y credenciales. Ningún método de almacenamiento o comunicación elimina todos los riesgos.

7. Cambios en esta política

Esta página se actualizará cuando cambien las prácticas descritas. La fecha al inicio permite identificar la versión vigente. Para dudas sobre un cambio, utiliza el canal de soporte del proyecto.
