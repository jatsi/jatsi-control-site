Preguntas frecuentes

¿La web funciona si JATSI Control está cerrado?

Sí. La presentación, la guía, la ayuda y las páginas legales se alojan como un sitio independiente. Puedes consultarlas y compartirlas aunque el servicio local esté apagado.

¿Puedo controlar mi directo desde esta página?

El control del LIVE ocurre en la aplicación de escritorio para Windows. Las escenas de esta web muestran ejemplos con datos ilustrativos. Para conectar canales y ejecutar overlays o automatizaciones, utiliza la aplicación instalada en tu equipo.

¿Tengo que conectar todas las herramientas?

Puedes usar las integraciones que encajen con tu contenido. Las conexiones opcionales pueden requerir cuentas, permisos, credenciales, configuración de la herramienta externa o versiones compatibles. Revisa cada integración antes de utilizarla en un LIVE.

¿Cómo añado un overlay a OBS?

Configura el overlay en JATSI Control y copia la URL de fuente de navegador que genere la aplicación. Añade una fuente Navegador en OBS y pega esa URL. Mantén JATSI Control abierto para que el overlay local pueda recibir actividad.

¿Por qué no aparece actividad de mi canal?

Comprueba el perfil y el canal seleccionados, el estado de conexión, la disponibilidad del directo y los permisos de la integración. Para una herramienta externa, revisa que esté abierta y que su conexión esté habilitada. Si continúa, comparte la versión, los pasos y el mensaje de error en un reporte, ocultando credenciales y datos personales.

¿Este sitio inicia sesión o cierra mi sesión de TikTok?

Este sitio informativo no ejecuta autorizaciones de TikTok ni revoca accesos. La conexión de TikTok LIVE por canal de la aplicación es distinta de TikTok Login Kit. Para revisar permisos ya concedidos a aplicaciones, utiliza las opciones de cuenta de TikTok o del proveedor correspondiente.

¿Dónde se guarda la configuración?

La aplicación guarda perfiles, ajustes e historial en el equipo. Las integraciones se comunican con sus proveedores cuando las utilizas. Las credenciales se guardan mediante el almacén del sistema cuando está disponible, con un mecanismo alternativo de archivos locales para otros entornos. Consulta la política de privacidad para más detalles.

¿Cómo solicito acceso o eliminación de datos?

Para información que hayas compartido con el proyecto en GitHub, abre una solicitud con el enlace del reporte que quieras revisar o retirar. Los reportes son públicos: no añadas información sensible y pide un canal adecuado si fuera necesario. Para datos locales de la aplicación, solicita orientación sobre la versión que utilizas; este sitio no puede acceder a los archivos de tu equipo.

CONTACTO DEL PROYECTO

Cuéntanos qué necesitas.

Para consultas, solicitudes de acceso, reportes de funcionamiento o gestión de información compartida, utiliza GitHub Issues. Para un problema, incluye la versión de JATSI Control, tu versión de Windows, la integración afectada y los pasos para reproducirlo.

El canal es público. Oculta claves, tokens, contraseñas, URLs privadas y datos de tu audiencia antes de compartir capturas o registros.
